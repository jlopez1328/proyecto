# NexusStock

La aplicación actualizada está en **[proyecto_1](proyecto_1/README.md)**, organizada en modelo, vista y controlador.

Abre esa carpeta en Visual Studio Code y ejecuta `npm ci` y `npm run local`. La documentación de instalación, MongoDB, uso y configuración está en [proyecto_1/docs](proyecto_1/docs/INSTALACION.md).

La carpeta `.github` permanece en la raíz para ejecutar las comprobaciones y la automatización del tablero Scrum. Las claves, configuraciones privadas y bases locales quedan excluidas de Git.
